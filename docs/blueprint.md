# **App Name**: Pool Control 1.0

## Core Features:

- Control de Tiempo de Mesa: Permite iniciar y detener el tiempo de cada mesa de billar, calculando automáticamente el costo basado en la tarifa configurada.
- Registro de Ventas: Registra las ventas de productos (bebidas, accesorios) y servicios (tiempo de mesa) con detalles de fecha, hora y monto.
- Gestión de Inventario: Administra el inventario de bebidas y accesorios, con alertas de stock bajo.
- Almacenamiento de Datos: Usa Firestore para la persistencia de datos, gestión de usuarios y toda la información relacionada a la aplicación.
- Recomendación de ofertas: Usa Genkit para la recomendación de ofertas personalizadas a los clientes.

## Style Guidelines:

- Color primario: Azul profundo (#3498db) para reflejar un ambiente acuático y elegante.
- Color de fondo: Azul muy desaturado (#e7f5ff) para complementar el tema oceánico.
- Color de acento: Amarillo dorado (#f1c40f) para resaltar elementos clave y llamadas a la acción.
- Fuente de títulos: 'Playfair', fuente serif, para un diseño elegante.
- Fuente de cuerpo: 'PT Sans', fuente sans-serif, para una mejor lectura en general.
- Iconos minimalistas y modernos en color amarillo dorado para representar las diferentes funciones del dashboard.
- Diseño limpio y ordenado, con una barra de navegación lateral para acceder a las diferentes secciones (mesas, ventas, inventario).
- Transiciones suaves y sutiles al cambiar entre secciones y al interactuar con los elementos de la interfaz.
